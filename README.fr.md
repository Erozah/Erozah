# Bonjour 👋, moi c'est Erozah

Développeur logiciel orienté architectures backend, clean code et outils interactifs temps réel. Je conçois des API REST robustes, des systèmes offline-first et des interfaces web réactives.

---

### 🚀 Projets Phares

- **[Spicetify Visualizer Engine](https://github.com/Erozah/spicetify-visualizer)** : Moteur de visualisation audio 60 FPS pour Spotify.
  - Architecture modulaire SOLID supportant l'injection dynamique de "Mod Packs" (Cyber Cat, Cosmic Cat, Red Panda).
  - Rendu Canvas 2D natif, analyse fréquentielle FFT, physique de particules par intégration de Verlet et animations procédurales.

- **[Plateforme Square Games](https://github.com/Erozah/square_games)** : Moteur modulaire de jeux de plateau au tour par tour.
  - API Spring Boot et interface web pour Morpion, Puissance 4 et Taquin.
  - Architecture extensible par plugins, double couche de persistance JPA et Spring JDBC, et sécurisation par jetons JWT (RSA).
  - Couplé avec un [Microservice Utilisateurs](https://github.com/Erozah/square_games_users) dédié.

- **[Wifi Signal Tracker](https://github.com/Erozah/Wifi_signal_tracker)** : Outil de mesure de signal Wi-Fi temps réel et benchmark résidentiel.
  - Mesure instantanée (dBm), inspection des canaux et latence vers la passerelle.
  - Historique 60 FPS sur Canvas avec retours sonores interactifs (Web Audio API / mode compteur Geiger).
  - Benchmark par pièce avec accès mobile via QR code.

- **[Donjons & Dragons](https://github.com/Erozah/D-D)** : Jeu de plateau tour par tour développé en Java.
  - Modélisation objet du domaine (personnages, équipements, gestion d'état du plateau).
  - Moteur de jeu modulaire et interface interactive en ligne de commande.

- **[Portfolio](https://github.com/Erozah/Portfolio)** : Site vitrine personnel responsive.
  - Développé en HTML5 sémantique, CSS moderne (Grid, Flexbox, variables CSS) et JavaScript vanilla.
